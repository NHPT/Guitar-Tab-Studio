# 内置演示曲目

默认曲目为美国公共领域传统歌曲 `Wayfaring Stranger`，采用 Guitar Tab
Studio 编写的 64 小节初学编配，速度 88 BPM，时长约 2:55。

## 来源与许可

- 旋律与歌词属于公共领域。
- 吉他编配由 Guitar Tab Studio 编写。
- 吉他音频由仓库脚本确定性合成。
- 引导人声由本机语音与音高拟合脚本合成，不包含真人演唱采样。
- 编配清单、录音和引导人声按项目 Apache-2.0 许可分发。

编配清单记录了来源参考、旋律指纹、录音生成方式和每个弦品事件。发行包不包含
第三方商业录音，也不包含商业录音生成的分轨。

## 音轨

默认播放器提供两条可播放音轨：

- `吉他`：旋律与交替低音编配的确定性合成录音；
- `人声`：与歌词和旋律同步的本地合成引导音。

贝斯、鼓组、键盘和其他轨保留为空状态，界面不会用重复音频伪造不存在的分轨。

## TAB 与节奏

TAB 由 `wayfaring-stranger-beginner.json` 的绝对弦品事件直接构建，不经过
自动转录。清单使用 4/4 拍、E minor、0 品变调夹和每拍 12 tick；跨小节延音在
生成分析文档时合并，音高始终满足标准调弦开弦音加绝对品位。

## 校验

`npm run demo:audio:check` 校验：

- 公共领域来源和原创录音声明；
- 编配清单与 ABC 来源指纹；
- 两个 WAV 的 PCM 格式、时长、大小和 SHA-256；
- 吉他与引导人声音频不是同一文件；
- 每个弦品事件的范围、节拍容量和音高等式。
