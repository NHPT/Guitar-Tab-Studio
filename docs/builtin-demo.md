# 内置演示曲目

默认曲目为 John Denver 的 `Take Me Home, Country Roads`：

- 来源：<https://music.163.com/#/song?id=1478037>
- 时长：约 3:14
- 检测速度：161.5 BPM
- 检测调性：A major
- TAB：132 小节、1789 个音符

## 生成方式

内置项目由与桌面分析任务相同的 Worker 流程生成。Basic Pitch 提取音符，
Demucs 分离声部，指板映射生成绝对弦品位置，和弦与技法检测结果保留模型
置信度，供用户继续校对。

## 音轨

默认播放器提供 7 条可独立控制的音轨：

- `人声`
- `吉他 1`
- `吉他 2`
- `贝斯`
- `鼓组`
- `键盘`
- `其他`

## TAB 与节奏

TAB 读取 `take-me-home-country-roads-analysis.json`，保留标准调弦下的
绝对物理品位。变调夹为独立元数据，默认 0 品，不参与弦品换算。当前结果来自
自动转录，尚未通过人工金标准审核。

## 校验

`npm run demo:audio:check` 校验：

- 默认项目的标题、作者、时长、速度、调性和来源记录；
- MP3、M4A 分轨和双吉他分轨的 SHA-256；
- 分析文档中的音符、和弦区间与吉他分轨数量；
- 每个音符的弦号与绝对品位范围。
