# 内置演示曲目

默认曲目为唐朝的《国际歌》：

- 来源：本机授权媒体导入
- 时长：约 4:27
- 典型速度：98.1 BPM（内部保留逐拍 Tempo Map）
- 检测调性：G major
- TAB：1462 个音符、107 个按实际拍点切分的和弦区间

## 生成方式

内置项目由与桌面分析任务相同的 Worker 流程生成。Basic Pitch 提取音符，
Demucs 分离声部，指板映射生成绝对弦品位置，和弦与技法检测结果保留模型
置信度，供用户继续校对。

## 音轨

默认播放器提供 6 条可独立控制的音轨：

- `人声`
- `吉他`
- `贝斯`
- `鼓组`
- `键盘`
- `其他`

## TAB 与节奏

TAB 读取 `internationale-analysis.json`，保留标准调弦下的
绝对物理品位。变调夹为独立元数据，默认 0 品，不参与弦品换算。当前结果来自
自动转录，尚未通过人工金标准审核。

播放同步始终使用原始起音时间；谱面位置单独量化到附近的四分、八分、
三连音或十六分网格。渐快、渐慢和自由速度不会被改写成固定 BPM，逐拍
速度变化保存在 Tempo Map 中。

拍点优先取自鼓轨，并用和声变化确认 4/4 强拍相位。开头在首个完整强拍前
保留 1 拍弱起：弱起从 `0.3317s` 开始，首个完整小节从 `0.9433s` 开始，
不会再把原混音中的 `0.209s` 瞬态误当成小节起点。

## 校验

`npm run demo:audio:check` 校验：

- 默认项目的标题、作者、时长、速度、调性和来源记录；
- Ogg 主音频和 M4A 分轨的 SHA-256；
- 分析文档中的音符、和弦区间与聚合吉他谱数量；
- 每个音符的弦号与绝对品位范围。
