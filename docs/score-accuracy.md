# 曲谱准确度与时间策略

## 时间语义

系统不修改原始演奏速度。每个音符保存两类位置：

- `at`：原始演奏时间，用于音频同步和误差评测。
- `notationAt` / `notationBeat`：谱面位置，仅在接近四分、八分、三连音
  或十六分网格时量化。

逐拍速度保存在 `tempoMap`。速度变化超过稳定阈值时标记为 `variable`，
渐快、渐慢和 rubato 继续使用原始拍点；练习校准版必须作为独立派生版本，
不得覆盖原始时间轴。

有可用鼓轨时，四分音符网格优先比较鼓轨与原混音的连续性；只有速度一致且
鼓轨显著更稳定时才切换。随后用和声变化定位循环强拍，并将首个完整强拍前的
演奏保留为 1–3 拍弱起小节。

## 优化顺序

1. 拍点、小节线和起音。
2. 音高与重复拨弦。
3. 弦号与品位路径。
4. 和弦根音与性质。
5. 已审核技法。

弦品分配使用有限窗口的序列搜索，同时约束同一音组不占用同一根弦、
把位跨度和连续移动。和弦窗口跟随实际拍点，不按全局 BPM 等宽切分。

## 完整曲谱门禁

`npm run score:evaluate -- ...` 生成分层报告，
`npm run score:gate -- ...` 检查：

- 拍点 F1 不低于 `0.95`，拍点中位误差不超过 `20ms`。
- 起音、音高和 TAB F1 均不低于 `0.90`。
- 重复拨弦召回不低于 `0.90`。
- 和弦完整准确率不低于 `0.90`。
- 有技法参考时，技法精确率不低于 `0.90`。

任何层未达标，候选谱都不能标记为已校准。

节拍参考集必须遵循
[节拍层金标准](beat-gold-standard.md)的双人独立标注与第三方裁决流程；
模型候选拍点不能直接转为金标准。

## 《国际歌》长期回归

内置分析已接入 Tempo Map、序列弦品优化和实际拍点和弦窗口。自动结果导出到
隔离的 `candidate.jsonl`，状态固定为 `quarantined`，在完成节拍、音符、
弦品、和弦和技法五层审核前不能参与模型门禁，也不能称为金标准。
